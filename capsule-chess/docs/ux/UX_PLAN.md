# UX/UI 기획 — 더 많은 사람이 시작하고, 내일 또 오게

> 작성: 2026-10-05 · 목표 지표: 첫 판 완료율, 다음 날 재방문율(D1), 7일 재방문율(D7), 데일리 퍼즐 참여율

## 1. 사용자 흐름 점검

설치 → **첫 화면** → **첫 판** → **이기고/지고** → **내일 다시 오기** 순서로 사람을 놓치는 지점을 찾았다.

| 단계 | 문제 | 영향 |
|---|---|---|
| 첫 화면 | 같은 크기 버튼 5개 나열. 무엇부터 할지 안 보임 | 첫 탭 망설임 → 이탈 |
| 첫 화면 | 연속 기록·진행도가 안 보임 | 다시 올 이유가 약함 |
| 이어하기 | 단계 목록에 들어가 다음 단계를 찾아야 함 (탭 3번) | 짧은 세션에서 귀찮음 |
| 게임 중 | "현재 턴: 블루/레드"는 체스 용어 느낌 | 초보 혼란 |
| 게임 중 | 실수 한 번이면 판이 망가짐, 무르기 없음 | 초보 좌절 → 이탈 |
| 퍼즐 | 막히면 출구가 없음 | 데일리 퍼즐 포기 → 연속 기록 끊김 |
| 다음 날 | 다음 퍼즐까지 남은 시간·알림 없음 | 재방문 신호 없음 |
| 화면 크기 | 큰 휴대폰에서도 보드 340px 고정, 작은 휴대폰에서 홈 잘림 | 보기 불편 |

## 2. 이번에 바꾼 것 (2026-10-05)

- **홈 재설계 (정보 위계)**
  - 상단: 🔥 연속 기록, ★ 별, ⚙️ 설정 (설정은 메뉴에서 아이콘으로 내림)
  - 가장 큰 카드: 오늘의 퍼즐 — 안 풀었으면 "오늘 풀면 🔥 N일 연속!"으로 동기 부여, 풀었으면 "다음 퍼즐까지 HH:MM:SS"
  - 이어하기 카드: 탭 한 번에 다음 단계 시작 + 진행 막대 (N/20 단계, ★ N/60)
  - 작은 타일: 체스 배우기(처음 온 사람에게 강조), 자유 대전
- **게임 화면**
  - AI 대전은 "내 차례 / AI가 생각 중…", 2인 대전은 "블루 차례 / 레드 차례" + 색 점
  - 무르기: AI 대전에서는 AI 수와 내 수를 함께 되돌려 바로 내 차례로. 무르기는 애니메이션 없이 즉시 반영
  - 보드 최대 크기 340 → 400 (큰 휴대폰·태블릿)
- **데일리 퍼즐**
  - 💡 힌트: 움직여야 할 기물을 빛나게. 힌트 사용 수는 공유 결과에 💡로 표시 (솔직한 공유)
  - 다 풀면: 다음 퍼즐까지 남은 시간, "단계별 도전 이어하기"로 세션 연장
- **매일 아침 9시 퍼즐 알림** (재방문 핵심 장치)
  - 첫 퍼즐을 푼 직후에만 "알림 받을까요?" 카드로 물어봄 (설치 직후 권한 팝업보다 수락률이 높은 시점)
  - 서버 없이 기기 안에서 예약, 설정에서 끄고 켜기
- **작은 화면**: 홈은 공간이 모자라면 스크롤

## 3. 2차로 바꾼 것 (2026-10-06)

- **분석 이벤트 기반** (`src/analytics.ts`): 첫 실행, 환영 안내 선택, 레슨 완료, 퍼즐 열기·힌트·오답·성공, 공유(이미지/텍스트), 알림 수락·거절, 단계 시작·종료(결과·수·별·무르기 횟수), 자유 대전 결과, 무르기, 설정 변경. **분석 서비스를 연결하기 전에는 아무 데이터도 보내지 않음**
- **마스코트 반응** (`src/components/MascotBubble.tsx`): 차례 표시를 캡슐 폰 말풍선으로 바꿈. 표정 5종(보통·웃음·놀람·고민·시무룩)과 상황별 대사(내 잡기 "좋은 수! 👍", AI 잡기 "앗, 잡혔어요!", 체크, 승패), 말이 바뀔 때 말풍선이 톡 튀어나옴
- **결과 공유 카드** (`src/components/ShareCard.tsx`): 퍼즐 결과를 마스코트·시도 이모지·🔥 연속 기록이 담긴 카드로 미리 보여 주고, 휴대폰에서는 이미지로, 웹에서는 텍스트로 공유
- **전용 기물 디자인**: 시안만 만들고 확인 대기 (마스코트처럼 잉크 외곽선 + 얼굴)

## 4. 3차로 바꾼 것 (2026-10-07)

- **어디서나 규칙 보기** (`src/components/RulesSheet.tsx`): 5×5 축소 규칙은 처음 보는 사람이 많아서, 모든 화면 헤더 오른쪽에 ? 버튼을 두고 홈에는 "? 규칙" 버튼을 둠. 누르면 아래에서 올라오는 안내가 열림
  - 기본 규칙 탭: 시작 배치 그림, 일반 체스와 다른 점 3가지(폰 한 칸·끝 줄 퀸·캐슬링/앙파상 없음), 체크·체크메이트·무승부
  - 기물 움직임 탭: 기물마다 작은 판에 갈 수 있는 칸(점)·잡을 수 있는 칸(빨간 테두리)을 그림으로
  - "직접 해 보며 배우기"로 튜토리얼 연결, 여는 횟수는 `rules_open` 이벤트로 측정
- **환영 안내·배우기 화면**: 규칙 차이를 같은 아이콘 목록으로 통일하고 "규칙은 언제든 ? 버튼에서" 안내 추가
- **안정성**: 안드로이드 Expo Go에서 알림 모듈 오류 수정, ♟가 이모지로 그려지던 문제 수정(글자 모양 고정), Expo 패키지 권장 버전으로 맞춤, 웹 전체 화면 자동 점검 스크립트(`scripts/smoke-web.mjs`)

## 5. 디자인 개편 "캡슐 리그" (2026-10-11)

몬스터 배틀 RPG 감성으로 전면 개편. 시안: `docs/design/`, 원본: `design/` (`node design/concept.mjs`)

- **기물 몬스터 12종** (`design/creatures.mjs` → `scripts/build-pieces.mjs` → `assets/pieces/`): 체스 실루엣은 그대로, 얼굴·발·팀 색. 작은 칸(56px)에서도 기물이 읽히는지 확인
- **배틀 화면**: 상대·내 팀 창 + 전력 게이지(잃은 기물만큼 줄어듦), 실황 대사 상자(글자가 한 자씩), 장난감 버튼
- **단계 시작 VS 화면**: 상대 이름·레벨, ★ 조건, 빠진 상대 기물 안내. 캡슐마다 5단계는 마스터전
- **진화 연출**: 폰이 끝 줄에 닿으면 폰↔퀸 실루엣이 깜빡이다 퀸 등장 (배틀·자유 대전·폰 레슨)
- **배지**: 캡슐 5단계를 다 깨면 배지, 홈에 배지 케이스. 단계 목록은 "캡슐 리그 지도"로
- **글꼴**: 한국어 주아, 영어 Fredoka (둘 다 OFL)
- **지킨 선**: 포켓몬 이름·캐릭터·몬스터볼 모양·로고 글꼴·유명 대사는 쓰지 않음 (스토어 심사·법적 위험)

## 6. 6차로 바꾼 것 (2026-10-11)

- **무르기 별 제한**: 무르기를 쓰면 그 판은 최대 ★★. VS 화면 조건("무르기 없이"), 첫 무르기 때 대사 상자, 결과 창에서 안내
- **공유 카드 3종** (`src/components/ShareCard.tsx`): 오늘의 퍼즐 + 단계 클리어(상대 몬스터·별·수) + 배지 획득. 결과 창에서 "📤 결과 공유 / 배지 자랑하기"
- **업적 13종** (`src/achievements/list.ts`): 첫 승리·첫 진화·완벽한 승리·배지·별 30개·퍼즐·연속 기록·졸업·강적 격파·2인 대전. 달성하면 위에서 알림이 내려오고(창이 떠 있으면 닫힌 뒤), 홈 트레이너 카드 → 업적 화면
- **스토어 대표 이미지** (`design/feature.mjs`): 블루 vs 레드 몬스터 구도로 새로 만듦
- 진행 기록 저장을 한 줄로 세워, 진화와 승리가 동시에 저장돼도 기록이 사라지지 않게 함
