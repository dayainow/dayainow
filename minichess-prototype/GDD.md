# 5x5 미니 체스 (Mini Chess) 기획서

## 1. 개요
* **게임명**: 5x5 스피드 체스 (가칭)
* **장르**: 보드게임 / 전략
* **목표**: 오리지널 체스의 복잡성을 줄이고, 1~3분 안에 한 판이 끝나는 빠르고 캐주얼한 모바일 웹/앱 게임 개발.

## 2. 보드 및 기물 세팅 (5x5 Grid)
보드는 5x5(가로 5, 세로 5)로 구성됩니다.

### 기물 배치
* **백 (White) - 아래쪽**
  * 1열 (Row 0): 룩(R), 나이트(N), 비숍(B), 퀸(Q), 킹(K)
  * 2열 (Row 1): 폰(P) x 5개
* **흑 (Black) - 위쪽**
  * 5열 (Row 4): 룩(R), 나이트(N), 비숍(B), 퀸(Q), 킹(K)
  * 4열 (Row 3): 폰(P) x 5개

## 3. 핵심 규칙 (간소화)
게임의 템포를 올리기 위해 몇 가지 복잡한 룰을 제거합니다.
1. **폰(Pawn)**: 첫 이동 시 2칸 전진 불가 (무조건 1칸 전진). 앙파상(En Passant) 없음. 폰이 끝까지 가면 '프로모션(Queen으로 자동 승급)' 적용.
2. **캐슬링(Castling) 없음**: 맵이 좁아 필요성이 낮음.
3. **체크 및 체크메이트**: 기존 체스와 동일하게 상대방의 킹을 잡을 수 있는 상태를 만들면 승리.
4. **턴**: 백이 먼저 시작하고 번갈아가며 진행.

## 4. UI/UX 디자인 방향
* 직관적인 드래그 앤 드롭 또는 터치 투 이동 (클릭 -> 목적지 클릭).
* 이동 가능한 칸 하이라이트 표시.
* 체크 상태일 때 킹 타일에 붉은색 경고 표시.

## 5. 개발 스택
* HTML5 / CSS3 (Grid layout)
* Vanilla JavaScript (순수 자바스크립트로 게임 로직 및 상태 관리 구현)
